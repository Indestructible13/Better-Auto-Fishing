# Better Auto Fishing
I've tried multiple other auto fishing mods, but none of them really had what I wanted. So I decided I could do better. This mod isn't super fancy, but it works, and it has the features I need. Feel free to enjoy it with me or fork it and make it your own! :)

## Features
 - Hotkey to activate/deactivate the mod
 - Configurable reel and cast delay
 - Randomize reel and cast delay option
 - Open water detection
 - Keep fishing while your inventory is open (can be disabled)
